# دليل منظومة استخراج ومحاذاة إحداثيات كلمات المصحف (`word_align`)

منظومة معيارية قابلة لإعادة الاستخدام لاستخراج وتحسين إحداثيات الكلمات (`x, y, width, height`) وعلامات رؤوس الآيات (`999`) والأرباع (`1001`) والسجدات (`1000`) لأي طبعة من طبعات المصحف الشريف، بما في ذلك الطبعات غير النمطية.

---

## 1. المتطلبات البيئية
- **Python 3.10+**
- الحزم المطلوبة:
  ```bash
  pip install opencv-python numpy pillow
  ```
- ملفات البيانات المرجعية (قابلة للتخصيص في `config.py`):
  - صور صفحات الطبعة (`PNG` أو `WEBP`) مرتبة بأرقام الصفحات (`2.png .. 522.png`).
  - قاعدة بيانات الكلمات المرجعية (`D:\Qeraat\QuranData\words.db`).
  - ملف النص العثماني (`D:\Qeraat\wathkro\public\data\quran_text.json`) للاستعانة بعدد المقاطع المتصلة في الرسم العثماني.

---

## 2. فكرة الخوارزمية (المحاذاة القسرية على مستوى المقاطع PAWs)
بدلاً من التقسيم الخطي التناسبي (الذي ينكسر عند الكلمات الممدودة بالكشيدة مثل `يَسْجُدُونَ` و`تَذَكَّرُوا`) أو التعرف البصري الأعمى (OCR)، تعتمد المنظومة على **المحاذاة القسرية (Forced Alignment)** بخطوات حتمية:

1. **فصل الحبر والإطارات (`anchors.py`):**
   - فصل الحبر الأسود للنص القرآني عن الإطارات والزخارف الملوّنة لعناوين السور.
   - إزالة خطوط إطارات الصفحات المزخرفة (مثل الفاتحة وأول البقرة) تلقائياً عبر فحص كثافة الأعمدة والصفوف.
   - فصل الحبر الأحمر/الدافئ لالتقاط علامات السجدة.
2. **كشف السطور وخطوط الأساس (`detect_lines`):**
   - حساب الإسقاط الأفقي المنعّم للحبر الأسود وتحديد ذرى خطوط الأساس والوديان الفاصلة بين السطور، مع مراعاة الفجوات الناتجة عن إطارات السور أو البسملة.
3. **التقاط نقاط الارتكاز الثابتة (`Hard Anchors`):**
   - **رؤوس الآيات (`wordsno = 999`):** استخراج الحلقات المغلقة (المكونات المتصلة التي تحتوي تجويفاً داخلياً للأرقام)، مع بديل آلي بمطابقة القالب (`cv2.matchTemplate`) عند تلامس الحلقة مع حرف أو تشكيل.
   - **علامات الأرباع (`wordsno = 1001`):** مطابقة قالب النجمة الثمانية (`cv2.matchTemplate`) المستخرج تلقائياً من صفحة مرجعية.
   - **علامات السجدة (`wordsno = 1000`):** التقاط المكون المتصل الدافئ/الأحمر المدمج (باستبعاد خط التسطير العلوي)، مع قالب احتياطي على الحبر الأسود.
4. **المحاذاة بالبرمجة الديناميكية (`aligner.py`):**
   - تقسيم كل سطر إلى مقاطع محصورة بين نقاط الارتكاز الثابتة.
   - استخراج المكونات المتصلة الأساسية للسطر (**PAWs** = أجزاء الكلمة العربية المتصلة) مع عزل التشكيل والنقاط وعلامات الوقف مؤقتاً، ومعالجة تلامس الكلمات النادر عبر الشق عند أضيق وادٍ رأسي.
   - تشغيل البرمجة الديناميكية (`DP`) لمواءمة تسلسل الكلمات المعروف مع تسلسل الـ `PAWs` من اليمين لليسار اعتماداً على:
     - تطابق عدد المقاطع المتصلة في الرسم العثماني (ثابت ولا يتأثر بالكشيدة).
     - مطابقة الحروف الطويلة (`ا ل ك ط ظ`) وبداية الألف المستقل (`الـ / أ / إ / ا`).
     - تفضيل الفراغات البيضاء الأكبر كحدود بين الكلمات.
     - وزن العرض النسبي بتكلفة مرنة (Huber) تتحمل الكشيدة دون إزاحة الكلمات المجاورة.

## 3. هيكل الملفات (`d:\editions\scripts\word_align\`)
| الملف | الوظيفة |
| :--- | :--- |
| `config.py` | تعريف إعدادات الطبعات (`EditionConfig`) وسجل الطبعات (`EDITIONS`). |
| `arabic_features.py` | تنظيف الرسم العثماني واستخراج خصائص كل كلمة (`exp_paws`, `weight`, `exp_tall`, `starts_alif`). |
| `anchors.py` | فصل الحبر والإطارات، كشف السطور، والتقاط رؤوس الآيات والأرباع والسجدات وبناء قوالبها. |
| `aligner.py` | استخراج الـ `PAWs`، المحاذاة بالبرمجة الديناميكية `DP`، وحساب درجة الثقة `confidence`. |
| `align_edition.py` | أداة سطر الأوامر للتشغيل متعدد الأنوية وتوليد `pages/*.json` و`<edition>_words.db` و`manifest.json`. |
| `qa_render.py` | أداة توليد صور الفحص البصري لمراجعة المربعات فوق صفحات المصحف. |

## 4. أوامر التشغيل

### تشغيل المحاذاة الكاملة لطبعة الشمرلي
```bash
python d:\editions\scripts\word_align\align_edition.py --edition shmrly --workers 8
```

### تشغيل صفحات محددة فقط (للاختبار السريع أو الضبط)
```bash
python d:\editions\scripts\word_align\align_edition.py --edition shmrly --pages 2,3,4,24,144,515,522 --workers 1
```

### توليد صور الفحص البصري (QA)
```bash
python d:\editions\scripts\word_align\qa_render.py --edition shmrly --pages 2,4,24,144,415,515 --out D:\Temp\qa_shmrly
```
ألوان المربعات في صور الفحص البصري:
- **أزرق:** الكلمات العادية (`n = 1..M`)
- **أحمر:** رؤوس الآيات (`n = 999`)
- **أخضر:** علامة الربع (`n = 1001`)
- **بنفسجي:** علامة السجدة (`n = 1000`)

## 5. كيفية إضافة طبعة جديدة (بما فيها الطبعات غير النمطية)
1. افتح `d:\editions\scripts\word_align\config.py` وأضف إدخالاً جديداً في قاموس `EDITIONS`:
   ```python
   'new_edition': EditionConfig(
       edition_id='new_edition',
       name='اسم الطبعة',
       pages_dir=os.path.join(EDITIONS_ROOT, 'new_edition', 'assets', 'edition', 'pages'),
       pages_from=1,
       pages_to=604,
       output_dir=os.path.join(EDITIONS_ROOT, 'words', 'new_edition'),
       page_col='page_number1',   # عمود رقم الصفحة في words.db
       x_col=None,                # ضع None في الطبعات غير النمطية التي بلا إحداثيات مسبقة
       y_col=None,
       w_col=None,
       rub_template_page=None,    # رقم صفحة تحتوي علامة الربع لاستخراج قالبها
       sajdah_template_page=None, # رقم صفحة تحتوي علامة السجدة لاستخراج قالبها
   ),
   ```
2. إذا كانت الطبعة **غير نمطية** (صفحاتها مختلفة الترقيم عن المدينة والشمرلي)، وفّر جدولاً يربط `page -> (surah, ayah, wordsno)` مع الحفاظ على ترتيب كلمات المصحف، واضبط معاملات مقاس الحلقة (`medallion_min_px`, `medallion_max_px`) وعتبة الحبر (`black_max_rgb`) بحسب دقة صور الطبعة.
3. شغّل الاختبار على 5 صفحات متنوعة أولاً (`--pages`) وافحصها عبر `qa_render.py`، ثم شغّل التوليد الكامل وراجع `flaggedPages` في `manifest.json`.

## 6. بنية المخرجات (`d:\editions\words\<edition>\`)
- **`manifest.json`**: البيانات الوصفية للإصدار (`schemaVersion: 2`, `yOrigin: "top"`)، إحصاءات الدقة الشاملة، وقائمة الصفحات التي تستدعي مراجعة (`flaggedPages`).
- **`<edition>_words.db`**: قاعدة بيانات SQLite موحدة بجدول:
  ```sql
  words(page, wordindex, surah, ayah, wordsno, aya_index, x, y, width, height, confidence)
  ```
- **`pages/<page>.json`**: ملف JSON مضغوط لكل صفحة بصيغة مصفوفة:
  ```json
  [{"id":62,"s":2,"a":5,"n":1,"ayaIdx":12,"x":0.8403,"y":0.0242,"w":0.1306,"h":0.0685}]
  ```
  - `x`: الحافة اليسرى كنسبة من عرض الصفحة (`0..1`).
  - `y`: **الحافة العلوية** كنسبة من ارتفاع الصفحة (`0..1`).
  - `w`: العرض كنسبة من عرض الصفحة (`0..1`).
  - `h`: الارتفاع كنسبة من ارتفاع الصفحة (`0..1`).
  - `n`: ترتيب الكلمة في الآية، أو `999` (رأس آية)، `1000` (سجدة)، `1001` (ربع حزب).
