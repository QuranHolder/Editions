# إحداثيات كلمات طبعات المصحف (`words/`)

يحتوي هذا المجلد على جداول إحداثيات الكلمات (الإصدار الثاني `schemaVersion: 2`) مقسّمة حسب كل طبعة في مجلد مستقل:

```text
words/
└── shmrly/
    ├── manifest.json       # بيانات الإصدار وتقرير الجودة الآلي
    ├── shmrly_words.db     # قاعدة بيانات SQLite موحدة لجميع الصفحات
    └── pages/
        ├── 2.json
        ├── ...
        └── 522.json
```

## مواصفات الإحداثيات (`schemaVersion: 2`)
جميع القيم نسب عشرية من `0` إلى `1` بالنسبة لأبعاد صورة الصفحة، مع نقطة أصل في الأعلى واليسار (`yOrigin: "top"`):
- `x`: الحافة اليسرى (`0..1`)
- `y`: الحافة العلوية (`0..1`)
- `w` / `width`: العرض (`0..1`)
- `h` / `height`: الارتفاع (`0..1`)

### القيم الخاصة لحقل `n` (`wordsno`)
- `1 .. M`: ترتيب الكلمة داخل الآية.
- `999`: علامة رأس الآية.
- `1000`: علامة السجدة.
- `1001`: علامة الربع.
